# Fonts and icons

Self-hosted so the app works offline. Fetched from npm, unmodified.

| File | Font | Use | Licence |
| --- | --- | --- | --- |
| `barlow-semi-condensed-latin-600-normal.woff2` | Barlow Semi Condensed 600 (`@fontsource/barlow-semi-condensed` 5.3.0) | headings (`h1`-`h3`, `font-heading`) | SIL OFL 1.1 |
| `inter-latin-wght-normal.woff2`, `inter-latin-ext-wght-normal.woff2` | Inter variable (`@fontsource-variable/inter` 5.3.0) | body text; `latin-ext` carries the peso sign | SIL OFL 1.1 |

Sidebar icons are Phosphor Icons 2.1.1 (`@phosphor-icons/core`, MIT), regular weight, inlined by the `icon` macro in `templates/_macros.html`.
